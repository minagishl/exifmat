# Manufacturer logos

SVG files live in `files/`. Import them from `svgs.ts` (Bun text imports); the build inlines them into `dist/`.

```bash
bun run minify-logos
```

After adding a logo, register it in `catalog.ts` and `svgs.ts`.

Brand names and logos are trademarks of their respective owners. Bundled for identification on user-generated photo frames only.
